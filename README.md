# IRONROOT

Irreversible Research Ecology for Robust Agent Evolution.

See [.github/copilot-instructions.md](.github/copilot-instructions.md) for the complete specification.

## Quick Start

```bash
# install
pip install -e ".[dev]"

# run tests
pytest

# start dev environment
./scripts/dev_up.sh

# run api
./scripts/run_once.sh
```

## Tech Stack

- Python 3.12+
- FastAPI
- PostgreSQL
- Redis
- Celery
